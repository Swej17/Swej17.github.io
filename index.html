GTA Clipper Uploader

A private, single-user tool for the Swej Gaming YouTube channel.

GTA Clipper Uploader runs on the channel owner's own computer. It uploads short, original, owner-reviewed videos to the owner's own YouTube channel, using YouTube's official API with the owner's permission. It is not offered to other users.

It is an independent fan project and is not affiliated with Rockstar Games, Take-Two Interactive, YouTube or Google.
